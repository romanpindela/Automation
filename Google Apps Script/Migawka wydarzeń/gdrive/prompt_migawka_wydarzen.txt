- Istotne decyzje samorządowe, strategiczne inwestycje infrastrukturalne, kluczowe zmiany prawne i podatkowe.
- Wydarzenia trwające obecnie, jeśli są aktywne w danym dniu i mają znaczenie społeczno-kulturalne albo rodzinne.
- Wydarzenia zapowiedziane na najbliższe 7 dni, jeśli mają sens dla rodziny i lokalnej społeczności.

### DODATKOWE WYMAGANIA - EKSTRAKCJA DANYCH SZCZEGÓŁOWYCH
Dla KAŻDEGO wyekstrahowanego wydarzenia MUSISZ dostarczyć WSZYSTKIE następujące pola:


1. Data / Dzień
   - Wpisz konkretną datę, np. "2026-09-28" lub "28.09.2026"
   - Jeśli wydarzenie trwa obecnie i nie ma konkretnej daty, wpisz "Trwa / data niepewna"
   - Jeśli występuje tylko okres typu "w najbliższych dniach", ale nie ma pełnej daty, wpisz "W najbliższych dniach"


2. Godzina
   - Jeśli dostępna dokładna godzina (np. 15:30), podaj ją
   - Jeśli tylko przedział (np. "popołudnie"), napisz przybliżenie: "14:00-18:00"
   - Jeśli brak informacji, wpisz "—"


3. Dla kogo (wiek)
   - Dla wydarzeń lokalnych rodzinnych: np. "Dzieci 4-7 lat", "Dzieci 5-12 lat", "Całe rodziny", "Wszyscy", "Dorośli"
   - Dla wydarzeń gospodarczych / politycznych: "Profesjonaliści", "Inwestorzy", "Ogół społeczeństwa", "Wszyscy", "—"
   - Jeśli brak informacji, wpisz "Wszyscy"


4. Tytuł / Temat
   - Krótki, zrozumiały tytuł wydarzenia lub tematu


5. Streszczenie merytoryczne
   - 1-3 zdania, zawierające sens wydarzenia, jego znaczenie i wartość dla użytkownika


6. Warunki wstępu
   - Dla wydarzeń lokalnych: "Wstęp wolny", "Wstęp płatny: 20 zł", "Wymagana rejestracja", "Publiczne", "Tylko dla członków", "Brak informacji"
   - Dla wydarzeń gospodarczych: "Publiczne", "Transmisja online", "Artykuł / Wiadomość", "Brak informacji"
   - Jeśli brak danych, wpisz "Brak informacji"


7. Źródło / Link
   - Zwróć dokładnie jedną komórkę w formacie:
     "Nazwa źródła — https://adres.pl"
   - Jeśli nie ma konkretnego linku, wpisz tylko nazwę źródła:
     "Nazwa źródła"


### WYMAGANIA DOTYCZĄCE STRUKTURY JSON
Zwracaj wyłącznie poprawny JSON obiekt w formacie:
{
  "dane": [
    ["Pole 1", "Pole 2", "Pole 3", ...]
  ]
}


Dla lokalnych wydarzeń emituj pola w tej kolejności:
["Obszar / Lokalizacja", "Data / Dzień", "Godzina", "Tytuł / Temat", "Streszczenie merytoryczne", "Dla kogo (wiek)", "Warunki wstępu", "Źródło / Link"]


Dla globalnych wydarzeń emituj pola w tej kolejności:
["Data wydarzenia", "Godzina", "Obszar / Zasięg", "Kategoria", "Tytuł / Temat", "Streszczenie merytoryczne", "Dla kogo (wiek)", "Warunki wstępu", "Źródło / Link"]

ZAKAZ REKONSTRUKCJI I ZMIANY DAT:
- Jeśli przy danym tytule/linku w tekście źródłowym nie ma PEŁNEJ daty dziennej i miesięcznej (np. '6 września', '06.09') lub data pochodzi z minionego miesiąca, KATEGORYCZNIE ODRZUĆ ten artykuł.
- NIGDY nie podstawiaj bieżącego miesiąca do samego numeru dnia! Jeśli widzisz samo '6' lub 'niedziela', a brak jednoznacznego potwierdzenia, że chodzi o nadchodzący tydzień — traktuj jako brak daty i POMIŃ wpis.
